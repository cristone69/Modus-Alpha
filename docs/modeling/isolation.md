# Nested Isolation

**Shortcut:** `Ctrl + F` in Object Mode

Nested Isolation lets you enter successive Local View levels rather than being limited to one isolation state.

## Basic use

1. Select one or more objects.
2. Press `Ctrl + F`.
3. Select a smaller subset inside the isolated view.
4. Press `Ctrl + F` again to isolate further.
5. Use the tool again to move back through the isolation stack.

The tool frames the current selection as part of the isolation workflow.
