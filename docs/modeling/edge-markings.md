# Edge Markings

Modus unifies common edge attributes in one workflow.

## Edge modes

The active mode can be:

- Bevel Weight
- Crease
- Seam
- Sharp

## Assign the active marking

**Shortcut:** `Shift + 2`

Assigns the current value or enabled marking to selected edges.

## Clear the active marking

**Shortcut:** `Alt + 2`

Clears the active marking from selected edges.

## Assign by Angle

Assign by Angle selects edges using the angle between adjacent faces and applies the active edge mode.

The default threshold is 30 degrees and can be changed from **Adjust Last Operation**.

## Clear Edge Markings

Clear Edge Markings can remove Bevel Weight, Crease, Seam, and Sharp data from every edge of all meshes currently in Edit Mode. Each marking type can be enabled or disabled in **Adjust Last Operation**.
