# Origin to Selected

The **Set Origin** tool places and orients the object origin using the active selected mesh element.

Supported active elements:

- vertex;
- edge;
- face.

## Basic use

1. Enter Edit Mode.
2. Make the desired vertex, edge, or face active.
3. Run **Set Origin** from the Shift+Q menu or Modus N-panel.
4. Return to Object Mode to inspect the new origin and orientation.
