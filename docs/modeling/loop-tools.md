# Loop Rotate and Force Loop

## Loop Rotate

**Shortcut:** `Alt + R`

Loop Rotate rotates selected edge loops along the surrounding surface.

## Force Loop

**Shortcut:** `Shift + Alt + R`

Force Loop cuts a connected mesh using a 3D plane perpendicular to the hovered edge.

It can continue through:

- quads;
- triangles;
- n-gons.

The operation stays on the connected mesh region and does not jump to disconnected geometry.

## Force Loop controls

During the modal operation, `C` toggles centering at the target edge. The same option is available in **Adjust Last Operation**.
