# Quick Boolean, Mirror, and Bevel Tools

## Quick Boolean

**Shortcut:** `Alt + Q` in Object Mode

1. Select the target object first.
2. Select one or more cutter objects.
3. Run Quick Boolean.
4. Choose Difference, Union, or Intersect from **Adjust Last Operation**.

Available solvers are Exact, Manifold, and Float.

Modus adds one Boolean modifier per cutter and moves cutters into its cutter collection.

## Mirror axes

The X, Y, and Z controls add or remove a cage-visible Mirror modifier on the chosen axis.

## Add Bevel

Adds a Bevel modifier configured for edge bevel weights. Existing Modus Bevel modifiers are preserved.
