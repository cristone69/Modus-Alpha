# Flick Symmetrize

**Shortcut:** `Alt + X` in Edit Mode

Flick Symmetrize uses a directional gesture to choose an object-local symmetry direction.

## Basic use

1. Enter Edit Mode.
2. Select geometry, or leave everything unselected.
3. Press `Alt + X`.
4. Flick toward the desired signed X, Y, or Z direction.
5. Confirm the operation.

## Selection scope

With context-based selection enabled:

- no selection defaults to the whole mesh;
- any mesh selection defaults to **Selected Only**.

These defaults can be changed in Modus preferences.

## Center cleanup

Optional center cleanup can:

- convert supported center triangle pairs to quads;
- remove hidden faces lying on the center plane.

Use **Adjust Last Operation** to review the final options.
