# UV Material Preview

UV Material inserts or removes a reversible Modus UV test shader.

## Grid options

Set these in Modus preferences:

- 1K, 2K, 4K, or 8K resolution;
- black-and-white UV Grid;
- Color Grid.

The generated image is shared instead of creating a separate grid for every object.

## Basic use

1. Select an object with a material.
2. Run **UV Material** from the Object Mode Shift+Q menu or Modus N-panel.
3. Enable Texture View if needed.
4. Run the command again to remove the reversible preview shader.
