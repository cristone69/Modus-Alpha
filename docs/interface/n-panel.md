# Modus N-panel

The Modus N-panel provides a persistent alternative to the Shift+Q popup.

## Open it

1. Place the mouse over the 3D Viewport.
2. Press `N`.
3. Select the **Modus** tab.

## Main panels

- **Tools:** context-aware modeling and object tools
- **Viewport:** viewport display controls
- **Topology Highlight:** live triangle and n-gon display settings
- **Modus Quad Engine:** Object Mode retopology and decimation

The Quad Engine panel is collapsed by default and only appears in Object Mode.
