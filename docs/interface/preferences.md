# Preferences and Persistent Settings

Open:

**Edit → Preferences → Add-ons → Modus**

## General preferences

Available settings include:

- Viewport Header Buttons
- N-panel Filtering
- triangle highlight color
- n-gon highlight color
- UV grid resolution
- UV grid style
- Flick Symmetrize defaults
- custom N-panel categories

## Keymaps

The **Keymaps** tab lets you change or disable every Modus shortcut.

## Automatic persistence

Modus automatically saves:

- preferences;
- N-panel categories;
- shortcut changes.

## Configuration controls

- **Export Settings**
- **Import Settings**
- **Reset Settings**
- **Delete Saved Configuration**

Use Export Settings before moving to another computer or testing a major configuration change.
