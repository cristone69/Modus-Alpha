# Quad Cylinder

Quad Cylinder creates a cylinder with quad-based caps designed for subdivision workflows.

## Main settings

- Vertices
- Radius
- Depth
- Horizontal Loops
- Bevel
- Bevel Width
- Inset Caps
- Smooth Shading
- Subdivision Modifier
- Subdivision Levels
- Bevel Modifier

## UVs

The primitive creates a UV map suitable for checking the cylinder with the Modus UV Material preview.

## Bevel workflow

The optional Bevel Modifier uses the cap-edge bevel weights generated by the primitive.
