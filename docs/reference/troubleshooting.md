# General Troubleshooting

## Modus does not appear

1. Confirm that Modus is installed and enabled.
2. Restart Blender.
3. Open a 3D Viewport.
4. Press `N` and look for the Modus tab.
5. Switch between Object Mode and Edit Mode.
6. Check Blender's system console for registration errors.

## A shortcut does not work

1. Confirm the active mode.
2. Move the mouse over the 3D Viewport.
3. Open Modus preferences and inspect Keymaps.
4. Search Blender's keymap for a conflicting command.
5. Change or disable one of the conflicts.
