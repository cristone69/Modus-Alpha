# Modus Features

## Workflow

- Shift+Q mode-aware quick menu.
- Matching Modus N-panel tools.
- Optional compact Tool Header controls.
- Editable persistent shortcuts.
- Optional N-panel tab filtering.
- Wireframe and Texture View controls.

## Modeling

- Nested object and component isolation.
- Flick Symmetrize with local-axis guides and selection scope.
- Relax and cleanup tools.
- Multi Grid Fill for 2–20 matching loops.
- Origin to Selected.
- Merge and edge-marking shortcuts.
- Unified Bevel Weight, Crease, Seam, and Sharp tools.
- Assign by Angle and Clear Edge Markings.
- Loop Rotate.
- Force Loop through quads, triangles, and n-gons.
- Live triangle and n-gon highlighting.

## Retopology

- Fast and Slow Retopology.
- Quick Decimate.
- X, Y, or Z symmetry.
- Sharp-edge boundaries.
- Optional Pre Smooth with 0–30 iterations.
- Quad smoothing controls.
- Optional Multiresolution and Shrinkwrap projection.
- Background processing, cancellation, and automatic result import.
- Original meshes stored in a hidden collection.

## Objects and modifiers

- Quick Boolean.
- Mirror-axis controls.
- Bevel modifier helper.
- Apply Mirror/Boolean.
- Finalize Bevel with supported n-gon repair and seam marking.

## Primitives

- Subdivision-ready Quad Sphere with UVs.
- Quad Cylinder with UVs, cap inset, edge-weight, crease, and bevel options.

## Materials and UVs

- UV Material preview.
- Shared 1K–8K UV Grid or Color Grid.
- Texture View in Solid shading.

## Persistence

- Automatic preference, category, and shortcut saving.
- Configuration import, export, reset, and delete controls.
